## Como usar
1. Responda **por escrito**, sem olhar o gabarito.
2. Corrija, e para cada erro anote **o porquê**, e não só a resposta certa.
3. Refaça os erros dois dias depois.
4. Quando errar um tema de forma repetida, volte ao guia em `docs/` e refaça o lab.
