# Glossário

| Termo | Significado |
|---|---|
| CE | Customer Edge, equipamento do cliente |
| PE | Provider Edge, borda da operadora |
| P | Provider, roteador de trânsito |
| OLT | Equipamento que concentra os acessos de fibra (PON) |
| ONU | Equipamento do cliente final ligado à OLT |
| LACP | Protocolo que negocia a agregação de portas |
| Eth-Trunk | Agregação de links da Huawei |
| Vlanif | Interface virtual (SVI) com IP dentro de uma VLAN |
| Loopback | Interface virtual que não cai; identifica o roteador |
| IGP | Protocolo de roteamento interno (OSPF, IS-IS) |
| BFD | Detecção rápida de falha de link |
| LDP | Distribuição de labels |
| RSVP-TE | Sinalização de túneis com engenharia de tráfego |
| FRR | Fast Reroute, proteção local imediata |
| VSI | Instância de VPLS |
| VRF | Tabela de rotas virtual por cliente |
| RD / RT | Route Distinguisher / Route Target |
| STP | Protocolo que evita loop em L2 |
| QinQ | Segunda tag VLAN (`dot1q-tunnel`) |
| OOB | Gerência fora de banda (porta MEth) |
